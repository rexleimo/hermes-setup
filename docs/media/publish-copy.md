想养一个自己的AI助手，但一看到命令行、部署、配置就劝退？这条视频就是给你的。

全程不敲一行命令：双击 start.bat → 浏览器里点几下 → 手机扫码接到微信 → 你的私人AI助手上线。苹果电脑把 start.sh 拖进终端也一样。

视频里你会看到：
· 一键安装：自动装环境装依赖，第一次大概一分钟
· 配"大脑"：13家模型供应商预设，GLM/Kimi 粘个 Key 就通
· 接微信：二维码弹在网页里，手机一扫自动回填，不用填任何东西（飞书、QQ、Telegram 等共14个平台随便接）
· 助手上岗：手机上发一句"你好"，它真的回了
· 完全免费开源，数据和代码分离，重装不丢；也可以给全家人搭一个统一入口，或纯内网隔离部署
