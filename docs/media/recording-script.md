# Hermes Console 宣传视频 · 演示段录制台本 v1

（接第一段：开场 + 产品介绍。以下按块录，每块单独成段，方便后期对轴剪辑。）

## 全局提醒
- 静音录屏，后期配音；OBS 1920×1080 60fps，只录窗口
- 用隔离演示环境录，画面里零真实密钥、零真实路径、零个人账号
- 弹窗、报错都别剪——是教学点
- 手机发消息镜头单独录（手机自带录屏），个人信息记得打码

---

## 块2 · 安装（约90秒）

【镜头】仓库页，红框圈住地址
台词：先去项目页把代码拿下来，GitHub 搜 rexleimo/hermes-setup，或者直接点评论区的链接。

【镜头】文件夹里鼠标悬停 start.bat 停1秒
台词：下载解压，Windows 用户什么都不用装，双击这个 start.bat 就行。

【镜头】双击 → SmartScreen 弹窗停2秒 → 点「更多信息」→「仍要运行」
台词：第一次运行，Windows 可能弹「已保护你的电脑」——别慌，未签名脚本都这样，不是病毒。点「更多信息」，再点「仍要运行」。

【镜头】终端滚动装依赖（后期加速，角标「1分钟→6秒」）
台词：然后它会自动装环境、装依赖，第一次大概一分钟。

【镜头】3秒后浏览器自动弹出 127.0.0.1:8420（慢放弹出瞬间）
台词：装完自动帮你打开浏览器，这个就是 Hermes Console 控制台。

【镜头】初始化向导设密码（密码打码）→ 进仪表盘
台词：第一次进来设个管理员密码——进来就是仪表盘：网关状态、模型、渠道、初始化清单，四步清清楚楚。

【镜头】补一句（可画外）
台词：苹果电脑的同学，把 start.sh 拖进终端按回车，一模一样。

---

## 块3 · 模型供应商（约90秒）

【镜头】点开「模型供应商」
台词：第一件事，给它配个大脑。点模型供应商——13 个官方预设，国内外主流全在。

【镜头】添加 GLM / Kimi 预设，粘贴 Key（打码）
台词：国内用户推荐 GLM 或者 Kimi，点添加，注册链接页面里都给好了，把 API Key 粘进来就行。

【镜头】点「拉取模型列表」
台词：然后点拉取模型列表，这家能用的模型全给你列出来。

【镜头】选主模型 → 点连接测试 → 变绿
台词：选一个设成主模型，点一下连接测试——绿的，通了。

【镜头】特写写入说明区
台词：顺便说一句，你的 Key 只存在本机配置里，页面永远不会回显，这点可以放心。

---

## 块4 · 消息渠道（约120秒）

【镜头】渠道墙全景（鼠标缓慢扫过）
台词：接下来是重头戏——消息渠道。飞书、微信、QQ、Telegram 在内，14 个平台随便接。

【镜头】飞书详情页，跟着 5 步引导走
台词：比如飞书，页面内置五步引导：建应用、粘 App ID、加机器人、开权限、发版——每一步还给你直达链接，根本不用翻文档。

【镜头】微信「接入助手」→ 二维码在网页里弹出 → 手机扫码（二维码后期模糊）
台词：最省事的是微信：不用填任何东西，点接入助手，二维码直接弹在网页里，手机一扫——自动回填、自动配置，连防打扰白名单都帮你写好。

【镜头】勾选启用 → 保存
台词：勾选启用、保存，渠道就活了。

---

## 块5 · 启动 Gateway（约90秒）

【镜头】服务管理 → 一键安装 Hermes → 启动网关
台词：最后一步，回服务管理：一键安装 Hermes，然后点启动网关。

【镜头】状态变绿特写（放大绿点）
台词：看这——状态三路探测，装没装好，它不会骗你。

【镜头】日志实时滚动
台词：日志实时刷新，出任何问题这里都能看到。

【镜头→切手机录屏】给机器人发「你好」→ 收到回复
台词：现在掏出手机，在飞书里给机器人发一句「你好」——你看，回了！到这儿，你的 AI 助手就算正式上岗了。

---

## 块6 · 进阶钩子（约45秒）

【镜头】记忆页、MCP 页、技能页三连快切（每页1.5秒）
台词：到这儿小白已经够用了。进阶玩家还有：记忆一键扩容、64 个官方 MCP 插件一键装、24 类技能库、审计日志、双重验证——这些留着以后单独出一期。

【镜头】仪表盘收尾全景
台词：对了，想内网隔离部署、或者给家里人搭个统一入口的，也都合适。

---

## 块7 · 收尾（约40秒）

【镜头】README 页，鼠标划过标题
台词：总结一下：想用 Hermes 又怕命令行的、想给全家人搭个 AI 助手的、要内网部署的——这个控制台都合适。完全开源免费，数据和代码分离，重装不丢。

【镜头】结尾卡（封面图 + 链接条 + 二维码）
台词：地址在简介和评论区，遇到问题去 GitHub 提 Issue。觉得有用的话，三连支持一下，我们下期见。
