Write Contract

对 Hermes 配置的写入契约

平台只写 Hermes 官方 schema 认可的键，并遵循官方推荐的安全实践。

  • 密钥隔离 — API Key 本体只写 ~/.hermes/.env，config.yaml 中仅存 key_env 键名
  • 原子写入 — 备份 → 校验 → 临时文件 → 原子替换，备份保留最近 10 份
  • 注释保留 — ruamel.yaml round-trip，config.yaml 手写注释完整保留
  • 最小写入面 — 供应商 / 主模型 / 别名 / 备选链 / 渠道各归其位，不越界改键
# config.yaml — 只写官方 schema 认可的键 providers: openrouter: base_url: https://openrouter.ai/api/v1 api_mode: openai_compatible key_env: HERMES_OPENROUTER_API_KEY # 密钥只在 .env model: provider: openrouter default: anthropic/claude-sonnet-4.5 delegation: fallback_providers: [ … ] # 降级备选链 platforms: feishu: enabled: true # 令牌写入 .env（600）
Security

严格鉴权，为公网部署而生

威胁模型驱动的安全设计，完整控制矩阵见 docs/SECURITY.md。

Argon2 密码哈希
TOTP 双因素认证
服务端会话 · 双过期
全站 CSRF 令牌
登录限流与账号锁定
IP 白名单 + 安全响应头
仅追加审计日志
密钥永不回显

生产部署建议：systemd 托管 uvicorn，前置 Nginx/Caddy 做 HTTPS（开启 HERMES_CONSOLE_SECURE_COOKIES=1），并用 HERMES_CONSOLE_ALLOWED_IPS 限制管理来源。

Quick Start

四步上线

控制台内的「初始化清单」会逐步引导同样的流程。

# 1. 安装依赖（自动创建虚拟环境） uv sync # 2. 配置环境变量（务必设置 HERMES_CONSOLE_SECRET） cp .env.example .env # 3. 启动 uv run uvicorn app.main:app --host 127.0.0.1 --port 8420 # 4. 打开 http://127.0.0.1:8420 — 首次访问进入管理员初始化向导

安装 Hermes Agent

「服务管理 → 一键安装」，执行官方 install.sh。

添加模型供应商

「模型供应商 → 添加预设」→ 拉取模型列表 → 设为主模型。

接入消息渠道

「消息渠道 → 飞书」，填入 App ID / App Secret 并启用。

启动 Gateway

「服务管理 → 启动 Gateway」，状态三路探测实时可见。
